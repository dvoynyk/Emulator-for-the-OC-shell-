Графический эмулятор командной строки UNIX-подобной операционной системы. Данный проект воссоздает пользовательский опыт работы с терминалом через специализированный графический интерфейс.

---

## 📋 Обзор Этапа 1

На текущем этапе реализован минимальный работоспособный прототип (REPL):
- Полноценный **графический интерфейс (GUI)** с областью вывода и строкой ввода.
- **Динамический заголовок окна**, формируемый на основе реальных данных операционной системы (имени пользователя и хоста).
- **Собственный парсер аргументов**, корректно обрабатывающий пробелы и кавычки.
- **Обработка ошибок** при вводе несуществующих команд или синтаксических сбоях.
- **Команды-заглушки** (`ls`, `cd`) и рабочая команда выхода (`exit`).

## 💻 Поддерживаемые команды на Этапе 1

| Команда | Тип | Описание | Пример использования |
| :--- | :--- | :--- | :--- |
| `ls` | Заглушка | Выводит имя команды и переданный список аргументов | `ls -l "My Documents"` |
| `cd` | Заглушка | Выводит имя команды и целевой путь (поддерживает пути с пробелами) | `cd "C:/Program Files"` |
| `exit` | Системная | Завершает работу эмулятора и закрывает окно приложения | `exit` |

## 🛠 Сборка и запуск

### Требования
- Компилятор с поддержкой **C++17** или новее
- Система автоматизации сборки **CMake** (версии 3.14+)

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/shell-emulator.git
   cd shell-emulator
2. Создайте директорию сборки и выполните компиляцию:
   ```bash
   mkdir build && cd build
   cmake ..
   make
   ```
3. Запустите эмулятор
   ```bash
   ./shell_emulator
   ```
